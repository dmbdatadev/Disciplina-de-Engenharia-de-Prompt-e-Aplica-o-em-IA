# Relatório de Automação IA - Hands-On Sprint

## Descrição do Projeto
Este projeto consiste em uma série de automações desenvolvidas para praticar a colaboração Humano-IA. Foram criados scripts para organização de arquivos, integração com APIs e sistemas de monitoramento condicional.

## Metodologia de Prompting
Para o desenvolvimento, utilizei um "Loop de Colaboração" estruturado:
1. **Instrução:** Definição de objetivos e restrições claras para a IA.
2. **Processamento:** Geração da lógica inicial via GitHub Copilot e Ghostwriter.
3. **Ajuste e Revisão:** Refatoração iterativa para garantir que o código seguisse padrões "Pythônicos" e seguros.

## Análise Crítica
A IA demonstrou força excepcional na geração de estruturas *boilerplate* e sugestões de sintaxe. No entanto, a intervenção humana foi indispensável para o tratamento de casos extremos (*edge cases*) e para garantir que as regras de negócio fossem aplicadas corretamente, como a prevenção de erros de permissão ao mover arquivos.
